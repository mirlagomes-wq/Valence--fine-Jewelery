
## Valence Fine-Jewelery
**1. Identificação e apresentação do projeto**
---
- Nome do projeto: Valence
- Tipo de projeto: Front-end
- Turma: 2º ano D
- Integrante:Mirla de Oliveira Gomes
- Professor: Josué Rodrigo Evangelista Figueirêdo

*Valence é um site desenvolvido para apresentar uma loja de jóias e semijoias. O objetivo é oferecer uma página organizada, permitindo que os usuários conheçam os produtos disponíveis e encontrem informações sobre a loja.*

**2. Objetivos e problema**
---

O principal objetivo do projeto é desenvolver um site que facilite a visualização dos produtos da Valence e torne a navegação mais simples para os usuários.
A ideia surgiu da necessidade de apresentar os produtos de uma forma mais organizada, reunindo informações e diferentes categorias em um único lugar.

**3. Funcionalidades**
---

O site possui as seguintes páginas e funcionalidades:
- Página inicial: apresenta a identidade da Valence e direciona o usuário para as outras páginas do site.
- Produtos: exibir os produtos disponíveis, organizados em categorias como brincos, conjuntos e anéis, com seus preços.
- Presentes: apresenta uma área voltada para opções de presentes.
- Contato: disponibiliza uma página para entrar em contato com a loja.
- Login: apresenta campos para preenchimento de nome completo e e-mail.

**4. Tecnologias e estrutura**
---

Para o desenvolvimento do projeto, foram utilizadas:
- HTML5: estruturação das páginas.
- CSS3: estilização e organização dos elementos.
- Visual Studio Code: ambiente utilizado para escrever e editar os códigos.

Também foram utilizadas imagens para apresentar os produtos e compor o visual do site.

**4.2 Estrutura do projeto**

O projeto foi organizado em arquivos HTML, responsáveis pelas diferentes páginas:

1. index.html — Página inicial.
2. produtos.html — Página de produtos.
3. contato.html — Página de contato.
4. Login.html — Página de login.
5. presentes.html — Página de presentes.

Os estilos CSS e as imagens utilizadas complementam a estrutura das páginas.

**5. Como executar o projeto?**
---
Para abrir e visualizar o site, basta seguir estes passos:

1. Baixar ou acessar a pasta do projeto.
2. Abrir a pasta no Visual Studio Code.
3. Localizar o arquivo index.html.
4. Abrir o arquivo em um navegador, como o Google.
5. Navegar pelas páginas utilizando os links disponíveis no site.

Não é necessário instalar aplicativos para visualizar o site.
