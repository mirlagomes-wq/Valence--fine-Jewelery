Identificação e apresentação do projeto<br>
Nome do projeto: Valence<br>
Tipo de projeto: Front-end<br>

Professor: Josué Rodrigo Evangelista Figueirêdo<br><br>
Valence é um site desenvolvido para apresentar uma loja de jóias e semijoias. O objetivo é oferecer uma página organizada,<br>
permitindo que os usuários conheçam os produtos disponíveis e encontrem informações sobre a loja.<br><br>
2. Objetivos e problema<br>
O principal objetivo do projeto é desenvolver um site que facilite a visualização dos<br>
produtos da Valence e torne a navegação mais simples para os usuários.
A ideia surgiu da necessidade de apresentar os produtos de uma forma mais<br>
organizada, reunindo informações e diferentes categorias em um único lugar.<br><br>
3. Funcionalidades<br>
O site possui as seguintes páginas e funcionalidades:<br>
Página inicial: apresenta a identidade da Valence e direciona o usuário para as outras páginas do site.<br>
Produtos: exibir os produtos disponíveis, organizados em categorias como brincos, conjuntos e anéis, com seus preços.<br>
Presentes: apresenta uma área voltada para opções de presentes.<br>
Contato: disponibiliza uma página para entrar em contato com a loja.<br>
Login: apresenta campos para preenchimento de nome completo e e-mail.<br><br>
4. Tecnologias e estrutura<br>
Para o desenvolvimento do projeto, foram utilizadas:<br>
HTML5: estruturação das páginas.<br>
CSS3: estilização e organização dos elementos.<br>
Visual Studio Code: ambiente utilizado para escrever e editar os códigos.<br>
Também foram utilizadas imagens para apresentar os produtos e compor o visual do site.<br><br>
4.2 Estrutura do projeto
O projeto foi organizado em arquivos HTML, responsáveis pelas diferentes páginas:<br>
index.html — Página inicial.<br>
produtos.html — Página de produtos.<br>
contato.html — Página de contato.<br>
Login.html — Página de login.<br>
presentes.html — Página de presentes.<br>
Os estilos CSS e as imagens utilizadas complementam a estrutura das páginas.<br><br>
5. Como executar o projeto?<br>
Para abrir e visualizar o site, basta seguir estes passos:<br>
Baixar ou acessar a pasta do projeto.<br>
Abrir a pasta no Visual Studio Code.<br>
Localizar o arquivo index.html.<br>
Abrir o arquivo em um navegador, como o Google.<br>
Navegar pelas páginas utilizando os links disponíveis no site.<br>
Não é necessário instalar aplicativos para visualizar o site.<br><br>
